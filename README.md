# ACTIVIDAD1_WEB

```
Comandos para ejecutar el código:

GET:
 -Ver la lista de incidencias ".../incidencias"
 -Buscar por Id la incidencia ".../incidencias/ #"
 -Ver estadísticas del arreglo ".../estadisticas"
 -Ver la clasificación de la incidencia ".../incidencias/#/clasificacion"

POST:
 -Crear una incidencia ".../incidencias"
   formato: {"empleado":"  ","area":"  ","descripcion":"  ","prioridad":" "} [Puede ser "Alta" "Media" "Baja"]

PUT:
 -Cambiar el estado de la incidencia ".../incidencias/:id/estado"
   formato:  {"estado":" "} [Puede ser "Pendiente" "En Proceso" "Resuelta" "Cancelada"]

DELETE:
 -Borra una incidencia ".../incidencias/ #"
```
